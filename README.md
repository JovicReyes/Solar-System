## Dipendenze
- Numpy
- Packaging
- Plotly
- Tenacity

## Istruzioni

1. Installare dipendenze: ``pip install -r requirements.txt``
2. Attivare ambiente virtuale (macOS): ``source venv/bin/activate`` 
3. Run: ``Python script.py``
